# HomeMusic для Android

Новый клиент этой установки, пакет `ru.llirkit.homemusic`, Android 8.0 и новее. Исходники полностью в этой папке.
Это отдельное приложение: оно не обновляет старый APK автора с пакетом `app.homemusic`.

**Скачать:** https://spotik.llirkit.ru/app/latest.apk. Эта же ссылка есть в веб-версии: «Ещё → Приложение для Android».
В первый раз Android попросит разрешить установку приложений из выбранного браузера.

## Возможности

- Вкладка HomeMusic открывает актуальный интерфейс вашего сервера: библиотека, поиск, миксы, импорт, ассистент.
  Встроенная версия сайта получает те же изменения, что веб-версия. По умолчанию указан `https://spotik.llirkit.ru`.
- Вкладка «Офлайн → Скачать»: выбрать песни из текущего микса или своего плейлиста. Скачиваются только песни,
  уже доступные на сервере. При необходимости сначала дождитесь их появления в миксе.
- Загрузки с уведомлением, проверкой полного аудиофайла, повтором ошибок и защитой от повторного сохранения.
  Допустимый размер одной песни — 256 МБ. Временный файл становится доступен плееру только после проверки.
- Нативный Media3-плеер: очередь сохранённых песен, перемотка, предыдущая/следующая песня, фоновая работа,
  системное уведомление, управление медиа-кнопками и пауза при отключении наушников.
- Сохранённая музыка доступна без сети после повторного запуска. Долгое нажатие удаляет копию только с телефона.
  Удаление приложения удаляет его локальную музыку; обычное обновление APK её сохраняет.

Онлайн-плеер остаётся плеером веб-версии. Нативное фоновое воспроизведение в этой версии относится к сохранённым
песням. Нет фоновой автосинхронизации плейлистов: сохранение выбранных песен запускается пользователем.

## Данные и сеть

Вход — в обычной форме HomeMusic; пароль не вшит в APK. Фоновые загрузки используют сессию WebView, не записывая
её в очередь. Перед загрузкой каждой песни проверяется аккаунт. Копии разделены по серверу и ID пользователя.
После подтверждённого выхода они скрываются до следующего входа в соответствующий аккаунт; без сети доступен
последний подтверждённый аккаунт. Смена сервера очищает вход, но не удаляет файлы прежнего аккаунта.

Только HTTPS с обычной проверкой сертификатов. Cookies не передаются на другой origin. Внешние ссылки открываются
в браузере; JavaScript-интерфейс сайта умеет только приостановить офлайн-плеер при запуске веб-аудио.
Музыка хранится в закрытом каталоге приложения; разрешения на все файлы/медиатеку телефона не запрашиваются.
Резервное копирование сессии и локальной музыки в облако/на другое устройство отключено.

## Сборка

Нужны JDK 21, Android SDK 36 / build-tools 36.0.0. Создайте локальный `local.properties` с `sdk.dir` либо задайте
`ANDROID_HOME`. Gradle Wrapper 8.13 включён в исходники.

```powershell
$env:JAVA_HOME = '<JDK 21>'
$env:HOMEMUSIC_SIGNING_PROPERTIES = '<закрытая папка>\signing.properties'
.\gradlew.bat :app:testReleaseUnitTest :app:lintRelease :app:assembleRelease
```

Файл свойств подписи (вне Git): `storeFile`, `storePassword`, `keyAlias`, `keyPassword`. Секреты не передаются в
аргументах Gradle. Храните ключ и пароль: будущие обновления должны иметь ту же подпись. Без переменной можно
собрать только обычный debug APK; публиковать его нельзя. При заданной переменной QA debug и release имеют одну
подпись, что позволяет проверять обновление без потери офлайн-файлов. Debug APK не публикуется.

Результат: `app/build/outputs/apk/release/app-release.apk`. Для публикации нужны проверка `apksigner verify`,
SHA-256 и manifest `latest.json`. Hub поддерживает отдельный каталог `ANDROID_RELEASES_DIR`; на этой установке
он равен `/data/android-releases` на SSD. Сначала публикуются неизменяемые APK, manifest заменяется последним.
Старый `scripts/release-android.ps1` предназначен для прежнего Tempus-клиента и для этой папки не используется.
