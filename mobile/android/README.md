# HomeMusic для Android

Версия **1.3.15** (`versionCode=19`): создание общего онлайн-радио из микса дня и из списка плейлистов. Кнопка радио находится рядом с «Поделиться» на странице микса и доступна у каждого непустого плейлиста. Сохранены фоновое воспроизведение радио и генерация ежедневного микса в 07:30. Требуется актуальный Хаб с веб-сборкой.

Версия **1.3.14**: ежедневная генерация миксов перенесена с 05:00 на 07:30 по часовому поясу Хаба. Нужен актуальный Хаб с веб-сборкой.

Версия **1.3.13** (`versionCode=17`): ссылки на треки, плейлисты и миксы для пользователей HomeMusic и публичный общий радиоэфир из плейлиста или волны. Радио воспроизводится нативным Media3-сервисом, включая свёрнутое приложение. Вход слушателю радио не нужен. Управление публикациями — «Ещё → Мои ссылки и радио». Нужен актуальный Хаб с веб-сборкой.

Версия **1.3.12**: ассистент продолжает поиск отсутствующего релиза по внешним музыкальным источникам и страницам композиторов. Полные аудиофайлы, опубликованные на прочитанной странице, скачиваются с исходными названиями и порядком в плейлист. Требуется актуальный Хаб.

Версия **1.3.11**: ассистент собирает плейлисты из конкретного альбома или OST только по найденному релизу. Если релиз не найден, сообщает об этом без подмены похожей музыкой. Требуется актуальный Хаб.

Версия **1.3.10**: восстановлена загрузка текстов песен через Хаб (HTTP/1.1 для LRCLIB). Обновите Хаб вместе с клиентами.

Версия **1.3.9** (`versionCode=13`): проверка обновлений внутри приложения, скачивание с прогрессом и установка через системное окно Android. Сохраняются нативное фоновое воспроизведение и управление в шторке.

Онлайн- и офлайн-плеер используют один медиасервис: одновременного воспроизведения нет. Media3 заранее
буферизует первые 10 секунд следующей песни после заполнения буфера текущей. В браузере сохраняется
предзагрузка одного файла до 32 МиБ.

«Аудиовыход» открывает системный переключатель на Android 14+. На прежних версиях и устройствах без
переключателя открывается панель громкости или настройки звука; доступные маршруты зависят от телефона.
Выбор применяется к онлайн- и офлайн-воспроизведению, маршрутизацией и отключением наушников управляет Android.

Новый клиент этой установки, пакет `ru.llirkit.homemusic`, Android 8.0 и новее. Исходники полностью в этой папке.
Это отдельное приложение: оно не обновляет старый APK автора с пакетом `app.homemusic`.

**Скачать:** https://spotik.llirkit.ru/app/latest.apk. Эта же ссылка есть в веб-версии: «Ещё → Приложение для Android».
В первый раз Android попросит разрешить установку приложений из выбранного браузера.

## Обновление из приложения

Начиная с 1.3.9 HomeMusic проверяет выбранный сервер при открытии приложения, не чаще одного раза в 6 часов.
Проверить вручную можно кнопкой **«Обновления»** в верхней панели, в том числе без входа в аккаунт.
Если новая версия найдена, приложение предлагает скачать её, показывает прогресс, затем кнопку **«Установить»**.
Загрузка не прерывает музыку. Окно можно скрыть и снова открыть кнопкой «Обновления».

Первый раз разрешите HomeMusic установку из этого источника в настройках Android и вернитесь в приложение.
Системный установщик попросит подтвердить обновление; после отмены можно повторить установку.
APK проверяется по размеру, SHA-256, имени пакета, версии и подписи установленного приложения.
При ошибке сети или проверки установка не запускается; доступна повторная попытка.
Скачанный и проверенный APK повторно используется, пока он находится в кеше приложения.
При закрытии приложения незавершённую загрузку потребуется запустить снова.

**Переход с 1.3.8 и более ранних версий:** один раз скачайте APK по ссылке выше и установите поверх текущего приложения.
После этого следующие обновления доступны из HomeMusic. Не удаляйте приложение: обычное обновление сохраняет вход
и скачанную музыку, удаление приложения стирает локальные файлы.

## Возможности

- Вкладка HomeMusic открывает актуальный интерфейс вашего сервера: библиотека, поиск, миксы, импорт, ассистент.
  Встроенная версия сайта получает те же изменения, что веб-версия. По умолчанию указан `https://spotik.llirkit.ru`.
- Вкладка «Офлайн → Скачать»: выбрать песни из текущего микса или своего плейлиста. Скачиваются только песни,
  уже доступные на сервере. При необходимости сначала дождитесь их появления в миксе.
- Загрузки с уведомлением, проверкой полного аудиофайла, повтором ошибок и защитой от повторного сохранения.
  Допустимый размер одной песни — 256 МБ. Временный файл становится доступен плееру только после проверки.
- Нативный Media3-плеер: онлайн- и офлайн-очереди, перемотка, предыдущая/следующая песня, фоновая работа,
  системное уведомление, управление медиа-кнопками и пауза при отключении наушников.
- Сохранённая музыка доступна без сети после повторного запуска. Долгое нажатие удаляет копию только с телефона.
  Удаление приложения удаляет его локальную музыку; обычное обновление APK её сохраняет.

Интерфейс онлайн-плеера и управление очередью остаются общими с веб-версией; звук и системная медиасессия
принадлежат Android-сервису и работают в фоне. Веб-сборка и APK должны быть актуальными. Нет фоновой
автосинхронизации плейлистов: сохранение выбранных песен запускается пользователем.

## Данные и сеть

Вход — в обычной форме HomeMusic; пароль не вшит в APK. Фоновые загрузки используют сессию WebView, не записывая
её в очередь. Перед загрузкой каждой песни проверяется аккаунт. Копии разделены по серверу и ID пользователя.
После подтверждённого выхода они скрываются до следующего входа в соответствующий аккаунт; без сети доступен
последний подтверждённый аккаунт. Смена сервера очищает вход, но не удаляет файлы прежнего аккаунта.

Только HTTPS с обычной проверкой сертификатов. Cookies не передаются на другой origin. Внешние ссылки открываются
в браузере. Мост сайта передаёт медиасервису очередь треков и команды плеера. Аудио запрашивается с текущими cookies только у выбранного HTTPS-сервера; перенаправления на другой origin запрещены.
Музыка хранится в закрытом каталоге приложения; разрешения на все файлы/медиатеку телефона не запрашиваются.
Резервное копирование сессии и локальной музыки в облако/на другое устройство отключено.

## Сборка

Нужны JDK 21, Android SDK 36 / build-tools 36.0.0. Создайте локальный `local.properties` с `sdk.dir` либо задайте
`ANDROID_HOME`. Gradle Wrapper 8.13 включён в исходники.

```powershell
$env:JAVA_HOME = '<JDK 21>'
$env:HOMEMUSIC_SIGNING_PROPERTIES = '<закрытая папка>\signing.properties'
.\gradlew.bat :app:testReleaseUnitTest :app:lintRelease :app:assembleRelease
```

Файл свойств подписи (вне Git): `storeFile`, `storePassword`, `keyAlias`, `keyPassword`. Секреты не передаются в
аргументах Gradle. Храните ключ и пароль: будущие обновления должны иметь ту же подпись. Без переменной можно
собрать только обычный debug APK; публиковать его нельзя. При заданной переменной QA debug и release имеют одну
подпись, что позволяет проверять обновление без потери офлайн-файлов. Debug APK не публикуется.

Результат: `app/build/outputs/apk/release/app-release.apk`. Для публикации нужны проверка `apksigner verify`,
SHA-256 и manifest `latest.json`. Hub поддерживает отдельный каталог `ANDROID_RELEASES_DIR`; на этой установке
он равен `/data/android-releases` на SSD. Сначала публикуются неизменяемые APK, manifest заменяется последним.
Старый `scripts/release-android.ps1` предназначен для прежнего Tempus-клиента и для этой папки не используется.

## Проверка фонового воспроизведения

В актуальном APK с актуальной веб-сборкой запустите онлайн-альбом из нескольких треков, сверните приложение
и заблокируйте экран. Музыка должна продолжаться, а в системной медиапанели должны отображаться название,
исполнитель, пауза, предыдущий/следующий трек и перемотка. Проверьте переход после окончания песни,
возврат в приложение и соответствие текущего трека веб-плееру. После запуска сохранённой песни онлайн-очередь
должна остановиться; повторный запуск онлайн-песни заменяет офлайн-очередь. Выход из аккаунта прекращает звук.

Для выпуска 1.3.4 проверены Android 15 (API 35) в эмуляторе: сворачивание, выключенный экран,
foreground service, системные пауза/продолжение/следующий трек, перемотка и автоматический переход дальше.

Для 1.3.9 на эмуляторе Android 15 повторно проверены офлайн-воспроизведение при сворачивании и выключенном
экране, foreground service, обложка, пауза, продолжение и следующий трек в системной медиапанели.
Проверены предложение обновления, загрузка и проверка подписанного APK с сервера, выдача разрешения,
системная установка, отмена и повтор, сохранение офлайн-файлов и ошибка при отключённой сети.
Онлайн-мост и синхронизация команд шторки проверены Playwright-тестом `web/tests/android-player.spec.mjs`;
повторный онлайн-прогон на физическом телефоне в этот выпуск не входил.
